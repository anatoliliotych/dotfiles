flash (jump)

sJump: type 2 chars, then the label
Space sSelect treesitter node (repeat to grow)
rRemote jump, operator-pending (e.g. yr)
f F t TSearch past the current line; matches get labels
f / FAfter f{char}: next / previous match (clever-f)
; ,Next / previous match
/ ?Search, with jump labels

Works in normal, visual and operator-pending modes. Esc cancels.
