tmux Cheat Sheet

prefix = C-Space  (hold A, tap Space - one hand)

Windows & sessions

C-Space tNew window, current dir
C-Space sNew session (prompts for name)
C-Space 1-9Jump to window N
C-Space wSwitch window / session (tree)
C-Space ffzf menu (sessions, windows, panes)
C-Space uZsh popup (85% of screen, current dir; Esc closes)
C-Space dDetach
C-Space iAgent popup: jump to waiting sessions

Panes

C-Space vSplit right (side by side)
C-Space bSplit down (stacked)
C-Space h j k lMove between panes (vim)
C-Space xKill pane

Copy & scroll

C-Space cCopy mode
C-Space pPaste
C-Space gThumbs: grab any text on screen

In copy mode: h j k l scroll, y copy, q quit.

State

C-Space aSave session state (auto-saved every 15 min anyway)
C-Space zRestore session state
C-Space rReload config
C-Space SpaceShow every keybinding
